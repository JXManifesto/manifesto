# JX Manifesto

This is the canonical source repository for the bilingual, versioned **Journalist Experience (JX) Manifesto**.

Journalist Experience is concerned with the quality of the tools, workflows, information flows, relationships, and working conditions that shape journalists' ability to do accurate, focused, and accountable work.

## Stable release

The first public version is **0.1**, published on June 25, 2026 and updated on August 5, 2026.

- [English permanent edition](https://jxmanifesto.org/en/versions/0.1/)
- [Persian permanent edition](https://jxmanifesto.org/fa/versions/0.1/)
- [English PDF](https://jxmanifesto.org/downloads/jx-manifesto-v0.1-en.pdf)
- [Persian PDF](https://jxmanifesto.org/downloads/jx-manifesto-v0.1-fa.pdf)

The files under `en/` and `fa/` are immutable snapshots of version 0.1. The unversioned working manifesto lives on the website and may include accepted changes intended for a future release.

## Repository structure

- `en/` — English Markdown and plain-text edition
- `fa/` — Persian Markdown and plain-text edition
- `research/FOUNDATIONS.md` — research notes, evidence boundaries, and open questions
- `CITATION.cff` — machine-readable citation metadata
- `.zenodo.json` — Zenodo deposit metadata
- `VERSIONING.md` — release and immutability policy
- `CHANGELOG.md` — public document history

## Evidence status

The manifesto is normative: it proposes what newsroom systems should value. JX is not yet a validated measurement instrument, certification, causal model, or scientific score. Research notes are maintained separately so adjacent evidence is not presented as direct validation of the framework.
